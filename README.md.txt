# Persiga-me

Jogo 2D feito em Godot (GDScript). Controlas o Pai Natal, que tem de fugir de um monstro que o persegue sem parar. O objetivo é chegar primeiro à cena final do jogo, em Luanda. Se o monstro o apanhar, o jogo reinicia.

## Controlos
- *Espaço*: saltar
- *A*: andar para a esquerda
- *D*: andar para a direita

## Como jogar
1. Instala o Godot Engine.
2. Abre o projeto (ficheiro project.godot).
3. Carrega em Play (F5).

## Tecnologias
- Godot Engine
- GDScript
